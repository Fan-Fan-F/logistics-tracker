# logistics-tracker · 物流轨迹跟踪

零依赖（原生 HTML/CSS/JS）的多承运商物流轨迹查询演示。输入运单号自动识别承运商，展示全链路节点进度条与详细时间线。

## 功能

- **承运商自动识别**：正则匹配顺丰 / 中通 / 圆通 / 京东 / EMS 五家单号规则
- **确定性轨迹生成**：同一单号多次查询结果一致（单号 + 发货时间派生随机源）
- **完整状态机**：已揽收 → 干线运输 → 转运中心 → 派送网点 → 派送中 → 已签收
- **异常事件模拟**：12% 概率插入天气延误提醒，时间线橙色高亮
- **节点进度条**：路由节点横向展示，已走过的绿色、当前节点高亮脉冲
- **预计送达 ETA**：按承运商时效系数（顺丰 1.6×、邮政 0.7×）动态计算
- **国内 / 跨境双线路**：跨境线（深圳保税仓 → 香港 → 法兰克福 → 柏林）时效 ×3

## 承运商时效模型

| 承运商 | 单号规则 | 时效系数 |
| --- | --- | --- |
| 顺丰速运 | `SF` + 12 位数字 | 1.6× |
| 中通快递 | `7` 开头 12-15 位 | 1.0× |
| 圆通速递 | `YT` + 13 位数字 | 1.0× |
| 京东物流 | `JD` + 14 位数字 | 1.4× |
| EMS 邮政 | `E` + 字母 + 9 位数字 + `CN` | 0.7× |

总时效 = 基础 72h ÷ 时效系数（跨境 216h），再叠加 ±15% 确定性抖动。

## 文件结构

```
C20-logistics-tracker/
├── index.html       # 查询区 + 概要卡 + 节点进度条 + 时间线
├── styles.css       # 时间线竖线、进度条、承运商徽标样式
├── track-engine.js  # 纯逻辑：承运商识别 / 轨迹生成 / 状态机
└── app.js           # 页面渲染与交互
```

## 本地运行

直接用浏览器打开 `index.html`，点击示例单号即可体验。接入真实环境时，将 `track-engine.js` 的 `generateTrace` 替换为快递鸟 / 快递 100 API 调用即可，渲染层无需改动。
